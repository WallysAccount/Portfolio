
# AGENTS.md

## Project Overview
Build a personal portfolio website for an NJIT Software Engineering student.
The website will showcase my background, education, interests, projects,
technical skills, and contact information.

## Pages
- index.html: Home page
- about.html: About Me
- projects.html: Projects
- skills.html: Skills
- contact.html: Contact

## Design
- Use a modern, professional software developer portfolio design.
- Use a charcoal or dark background with blue accents.
- Use readable fonts, consistent spacing, and clear navigation.
- Use responsive layouts for phones, tablets, and laptops.
- Use cards for projects and skills.

## Technology Rules
- Use plain HTML5, CSS3, and vanilla JavaScript only.
- Do not use frameworks, libraries, npm, or build tools.
- Use one external CSS stylesheet in css/style.css.
- Use JavaScript in js/script.js.
- Use relative paths for local files.
- Every page must have one h1, semantic HTML, and accessible navigation.
- Every image must have descriptive alt text.
- Do not add backend code, API keys, passwords, or tokens.
- The site must work by opening index.html locally.

## Features
- Responsive navigation menu with open and close controls.
- Light/dark mode toggle or another accessible interactive feature.
- Accessible buttons and keyboard navigation.
- No sideways scrolling on mobile screens.

## Git Rules
- Work on one task at a time.
- Review changes before committing.
- Commit each completed task with a clear message.
- Push changes to the main branch when approved.
- Never use reset or force push to undo changes.

## Testing
- Test each page on desktop and mobile screen sizes.
- Check all navigation links, images, and JavaScript features.
- Check keyboard accessibility and browser console errors.
- Update TESTING.md with test cases and actual results.
- Do not claim tests passed unless they have been run.
